# 硬體接線術語對照與混淆澄清指南 (Hardware Wiring Terminology Clarification)

> **版本**: 1.0  
> **最後更新**: 2026-09-04  
> **狀態**: 規範定案 (Approved)  
> **適用範圍**: HQ, Coli (IOTwawS3), 硬體安裝人員  

---

## 📌 問題背景

在實際接線作業中，「開分」這個詞會在不同情境下指向不同的硬體元件，導致混淆：

1. **開分按鈕** (實體按鈕)
2. **開分數字表** (實體分數顯示器)
3. **電腦台的開分訊號** (軟體控制訊號)

加上 **UI 腳位 (輸入)** 與 **UO 腳位 (輸出)** 的接線邏輯在傳統遊戲機與電腦遊戲機上完全不同，容易造成接線錯誤。

本文件旨在**明確定義術語**，並提供**快速對照表**，避免每次接線都需要重新思考架構。

---

## 🔧 1. 核心術語定義 (Core Terminology)

### 1.1 硬體元件術語

| 術語 (中文) | 術語 (英文) | 說明 | 物理特徵 |
|------------|------------|------|----------|
| **開分按鈕** | Credit-In Button | 玩家或操作員按下後，遊戲機增加分數 | 實體按鈕，按下時產生電氣訊號 |
| **洗分按鈕** | Credit-Out Button | 玩家或操作員按下後，遊戲機扣除分數 | 實體按鈕，按下時產生電氣訊號 |
| **開分數字表** | Credit-In Counter Display | 顯示入金（投幣/上分）累計的實體計數器 | 機械或電子式計數器，**會跳動顯示數字** |
| **洗分數字表** | Credit-Out Counter Display | 顯示出金（退幣/退分）累計的實體計數器 | 機械或電子式計數器，**會跳動顯示數字** |
| **分數顯示器** | Score Display | 遊戲機上顯示當前可玩分數的螢幕或數字管 | 僅顯示當前分數，不累計 |

### 1.2 採集卡腳位術語

| 術語 (中文) | 術語 (英文) | GPIO 名稱 | 方向 | 功能 |
|------------|------------|-----------|------|------|
| **UI 腳位** | Universal Input | UI1, UI2 | **輸入 (Input)** | 接收外部訊號，監測事件發生 |
| **UO 腳位** | Universal Output | UO1, UO2 | **輸出 (Output)** | 送出控制訊號，觸發外部裝置動作 |

## 🎮 2. 傳統遊戲機 (IC 板式) 接線架構

### 2.1 硬體特徵
- 內部是 **IC 板 + 接線**
- 有 **實體開分/洗分按鈕**
- 有 **實體開分/洗分數字表**（會跳動）

### 2.2 接線邏輯

```
┌─────────────────────────────────────────────────────────────┐
│                     傳統遊戲機 (IC 板式)                      │
├─────────────────────────────────────────────────────────────┤
│                                                               │
│  [開分數字表] ──跳動訊號──> UI1 (採集卡輸入腳位)             │
│       ↑                         │                             │
│       │                         ├─> 監測開分事件              │
│  [開分按鈕]                     │    (投幣/上分)              │
│                                                               │
│  [洗分數字表] ──跳動訊號──> UI2 (採集卡輸入腳位)             │
│       ↑                         │                             │
│       │                         ├─> 監測洗分事件              │
│  [洗分按鈕]                     │    (退幣/退分)              │
│                                                               │
│  ┌────────────────────────────────────────────────────────┐ │
│  │  遠端控制功能 (可選)                                    │ │
│  ├────────────────────────────────────────────────────────┤ │
│  │  UO1 (採集卡輸出腳位) ──控制訊號──> [開分按鈕]         │ │
│  │       │                                                  │ │
│  │       ├─> 模擬按鈕按下，觸發開分動作                    │ │
│  │                                                          │ │
│  │  UO2 (採集卡輸出腳位) ──控制訊號──> [洗分按鈕]         │ │
│  │       │                                                  │ │
│  │       ├─> 模擬按鈕按下，觸發洗分動作                    │ │
│  └────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────┘
```

### 2.3 接線重點

| 腳位 | 接線目標 | 功能 | 備註 |
|------|---------|------|------|
| **UI1** | **開分數字表** | 監測開分事件（投幣/上分） | **注意：接數字表而非按鈕**，因為數字表跳動才是真正的分數變化 |
| **UI2** | **洗分數字表** | 監測洗分事件（退幣/退分） | **注意：接數字表而非按鈕**，因為數字表跳動才是真正的分數變化 |
| **UO1** | **開分按鈕** (可選) | 遠端控制開分 | 模擬按鈕按下，觸發遊戲機開分動作 |
| **UO2** | **洗分按鈕** (可選) | 遠端控制洗分 | 模擬按鈕按下，觸發遊戲機洗分動作 |

### 2.4 為什麼 UI 要接數字表而非按鈕？

**關鍵問題**：如果 UI 接在按鈕上，可能會漏掉以下情況：
- 玩家直接投幣（未按按鈕），數字表跳動
- 遊戲機內部自動加分（例如獎勵分），數字表跳動
- 按鈕接觸不良，但數字表正常跳動

**解決方案**：UI 接在數字表上，**只要數字表跳動就能監測到**，無論是按鈕、投幣、還是內部自動加分。

## 💻 3. 電腦遊戲機 (完整電腦) 接線架構

### 3.1 硬體特徵
- 內部是 **一整台電腦**
- **沒有實體開分/洗分按鈕** (由電腦程式控制)
- **沒有實體開分/洗分數字表** (由電腦程式顯示)

### 3.2 接線邏輯

```
┌─────────────────────────────────────────────────────────────┐
│                  電腦遊戲機 (完整電腦)                        │
├─────────────────────────────────────────────────────────────┤
│                                                               │
│  [操作面板開分按鈕] ──按下訊號──> UI1 (採集卡輸入腳位)       │
│                                      │                        │
│                                      ├─> 通知電腦程式執行開分 │
│                                                               │
│  [操作面板洗分按鈕] ──按下訊號──> UI2 (採集卡輸入腳位)       │
│                                      │                        │
│                                      ├─> 通知電腦程式執行洗分 │
│                                                               │
│  ┌────────────────────────────────────────────────────────┐ │
│  │  未來擴充功能 (預留)                                    │ │
│  ├────────────────────────────────────────────────────────┤ │
│  │  UO1 (採集卡輸出腳位) ──> 預留 (例如：燈號控制)        │ │
│  │  UO2 (採集卡輸出腳位) ──> 預留 (例如：鎖機裝置)        │ │
│  └────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────┘
```

### 3.3 接線重點

| 腳位 | 接線目標 | 功能 | 備註 |
|------|---------|------|------|
| **UI1** | **操作面板開分按鈕** | 監測開分按鈕按下 | **注意：接按鈕而非數字表**，因為電腦遊戲機沒有實體數字表 |
| **UI2** | **操作面板洗分按鈕** | 監測洗分按鈕按下 | **注意：接按鈕而非數字表**，因為電腦遊戲機沒有實體數字表 |
| **UO1** | **預留** (未使用) | 未來可接燈號、警報器等 | 例如：「可開分」指示燈 |
| **UO2** | **預留** (未使用) | 未來可接鎖機裝置等 | 例如：「禁止操作」電磁鎖 |

### 3.4 為什麼 UI 要接按鈕而非數字表？

**關鍵問題**：電腦遊戲機沒有實體數字表，分數是由電腦程式控制顯示在螢幕上。

**解決方案**：UI 接在操作面板的按鈕上，當玩家或操作員按下按鈕時，採集卡捕捉訊號並通知電腦程式執行開分/洗分動作。

## 📊 4. 快速對照表

### 4.1 接線對照表

| 遊戲機類型 | UI1 接線目標 | UI2 接線目標 | UO1 接線目標 | UO2 接線目標 |
|-----------|-------------|-------------|-------------|-------------|
| **傳統遊戲機 (IC 板式)** | **開分數字表** | **洗分數字表** | 開分按鈕 (遠端控制) | 洗分按鈕 (遠端控制) |
| **電腦遊戲機 (完整電腦)** | **操作面板開分按鈕** | **操作面板洗分按鈕** | 預留 (燈號/警報器等) | 預留 (鎖機裝置等) |

### 4.2 術語混淆對照表

| 情境 | 常用說法 | 實際指的是什麼 | 正確術語 |
|------|---------|---------------|----------|
| 傳統遊戲機接線時說「UI1 接開分」 | **開分** | **開分數字表** (Counter Display) | **UI1 接開分數字表** |
| 傳統遊戲機接線時說「UO1 接開分」 | **開分** | **開分按鈕** (Button) | **UO1 接開分按鈕** |
| 電腦遊戲機接線時說「UI1 接開分」 | **開分** | **操作面板開分按鈕** (Panel Button) | **UI1 接操作面板開分按鈕** |
| 討論遠端控制功能時說「開分」 | **開分** | **透過 UO 腳位觸發開分動作** | **UO1 遠端控制開分** |

## ⚠️ 5. 常見錯誤與防呆提醒

### 5.1 傳統遊戲機常見錯誤

| 錯誤接法 | 問題 | 正確接法 |
|---------|------|---------|
| **UI1 接開分按鈕** | 可能漏掉投幣、自動加分等事件 | **UI1 接開分數字表** |
| **UO1 接開分數字表** | 無法驅動數字表跳動（數字表是被動顯示元件） | **UO1 接開分按鈕** |

### 5.2 電腦遊戲機常見錯誤

| 錯誤接法 | 問題 | 正確接法 |
|---------|------|---------|
| **UI1 接開分數字表** | 電腦遊戲機沒有實體數字表 | **UI1 接操作面板開分按鈕** |
| **UO1 接按鈕** | 電腦遊戲機不需要遠端控制按鈕（程式控制） | **UO1 預留或用於燈號控制** |

## 🔍 6. 決策流程圖

當你拿到一台遊戲機需要接線時，按照以下流程判斷：

```
開始接線
    │
    ├─> 這台遊戲機是什麼類型？
    │
    ├─> [傳統遊戲機 (IC 板式)]
    │       │
    │       ├─> 有實體開分/洗分按鈕嗎？ ──> 是
    │       ├─> 有實體開分/洗分數字表嗎？ ──> 是
    │       │
    │       ├─> UI1 接線目標：**開分數字表**
    │       ├─> UI2 接線目標：**洗分數字表**
    │       ├─> UO1 接線目標：**開分按鈕** (如需遠端控制)
    │       └─> UO2 接線目標：**洗分按鈕** (如需遠端控制)
    │
    └─> [電腦遊戲機 (完整電腦)]
            │
            ├─> 有實體開分/洗分按鈕嗎？ ──> 否 (由程式控制)
            ├─> 有實體開分/洗分數字表嗎？ ──> 否 (程式顯示)
            │
            ├─> UI1 接線目標：**操作面板開分按鈕**
            ├─> UI2 接線目標：**操作面板洗分按鈕**
            ├─> UO1 接線目標：**預留** (未來可接燈號等)
            └─> UO2 接線目標：**預留** (未來可接鎖機裝置等)
```
