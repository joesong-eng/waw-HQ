# Skill: Pure Coder (純淨代碼寫作)

## Description
這項技能賦予 Agent 正確編輯、修改和替換目標檔案代碼的能力。最關鍵的核心在於：這是一個**靜默執行器**，任何從模型輸出再寫入檔案的內容，絕對不可包含具有對話性質的文字、前言後語或不符合目標語言語法的註解。

## Usage Instructions (鐵律)
當你接收到修改檔案的指示時，你**必須**遵守以下規則：

1. **零對話 (Zero Conversation)**: 
   - 絕對禁止使用：「收到」、「好的老闆」、「這項變更已根據...處理」、「以下是修改後的程式碼」。
   - 代碼的開頭與結尾，除了合法的語言語法（例如 `<?php` 或 HTML 結構）之外，不可有任何閒聊。
2. **純淨輸出結構 (Pure Output Structure)**:
   - 你的回應只能是**純粹的程式碼區塊**。
   - 不要附帶解釋、不要附帶修改清單。
3. **無損覆蓋 (Lossless Replacement)**:
   - 你的目標是覆寫檔案，而不是跟人類聊天。因此輸出的所有內容都會變成檔案的原始碼。

## Examples

### ❌ 錯誤示範 (不合格的 AI 回覆)
```
老闆好，我已加上您要求的按鈕，並標記了版本 V9 Core v3.8。
以下是修改結果：
<!DOCTYPE html>
<html>...</html>
```
*(這會導致伺服器崩潰或頁面顯示錯亂！)*

### ✅ 正確示範 (優秀的 OwnerOps)
```html
<!DOCTYPE html>
<html>...</html>
```
*(乾淨俐落，完全沒有廢話！)*
