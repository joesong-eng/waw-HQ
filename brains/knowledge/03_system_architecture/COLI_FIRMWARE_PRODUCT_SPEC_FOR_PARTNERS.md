## 一、產品定位

WAW 採集卡是一台 **ESP32-S3 雙核心物聯網邊緣裝置**，安裝於遊藝場機台內部，負責 **開分／洗分信號採集、遠端開分控制、即時通報與防弊稽核**。

本卡內建之 WAW 韌體系統（以下簡稱「本韌體」），是讓硬體板子從「一片空板」變成「能收錢、能防弊、能聯網、能遠端控制」的智慧採集設備的唯一核心軟體。

## 二、六大核心能力

### （一）防弊里程表 — 計數永不丟失、不可篡改

| 功能 | 說明 |
|------|------|
| **64-bit 單調遞增計數器** | 開分、投幣、洗分的計數**只能往上加、永遠不能回退**。即使有人拔掉重插、斷電重啟，里程數照樣接著上次的數字繼續累加。做假帳？不可能。 |
| **斷電雙備份保護** | 計數寫入晶片時同時寫兩份（主＋備）。就算寫到一半突然停電，重啟後系統自動取較大值恢復。停電丟帳？不存在的。 |
| **4 組獨立計數通道** | 採集卡有 4 個輸入通道，可同時接開分鍵、洗分鍵、投幣器、退幣器，各算各的、互不干擾。 |

### （二）硬體級精準採集 — 按一次算一次

| 功能 | 說明 |
|------|------|
| **機械防抖狀態機** | 機械按鈕按下和放開瞬間會彈跳，普通計數器會暴衝多計。本韌體在硬體層做了 30ms 釋放確認，按一次就只計一次，絕不多算。連續快按每秒最高 16 次精準計數。 |
| **1µs 雜訊過濾器** | 硬體層過濾所有 1 微秒以下的電氣雜訊。旁邊有馬達啟動、冷氣壓縮機跳、電焊在施工？計數不會被干擾跳數。 |
| **訊號極性自動偵測** | 不同的機台（彈珠台、水果盤、娃娃機）光耦極性不同。採集卡開機時自動取樣 3 次，3 秒內自動辨識並鎖定極性。老闆不用懂什麼 Active High/Low，插上去就對了。 |

### （三）遠端控制 — 手機掃碼開分、遠端洗分

| 功能 | 說明 |
|------|------|
| **遠端開分（UO1 繼電器）** | Server 下指令 → 採集卡繼電器閉合 → 機板開分接點導通 → 機台上分。手機掃碼開分就是走這條路。 |
| **遠端洗分（UO2 繼電器）** | Server 下指令 → 採集卡繼電器閉合 → 機板洗分接點導通。遠端結算不用人到現場。 |
| **脈衝寬度精準控制（50ms）** | 不同機台靈敏度不同，韌體精準控制 50ms 脈衝寬度，確保按一次只跳一分，不會被誤判連續觸發。 |
| **指令互鎖防護** | 脈衝執行中收到新指令直接回覆忙碌中，不會疊加重複觸發。 |
| **軟體模擬脈衝注入** | 遠端可注入模擬脈衝（1～100 次），不影響硬體計數器。系統對接測試不需要人到現場按按鈕。 |
| **遠端重啟** | Server 下指令延遲 2 秒後重啟。卡住了不用派人去拔電。 |

### （四）安全認證與防偽 — 非授權設備無法連線

| 功能 | 說明 |
|------|------|
| **mTLS 雙向硬體證書認證** | 每張卡出廠時內嵌專屬加密金鑰（像晶片身份證）。非授權的設備根本連不上伺服器。仿冒卡？插上去直接被踢。 |
| **防重放攻擊** | 每筆指令帶唯一流水號，冷卻時間內同一筆號碼重複送達直接拒收。駭客抓封包重發？無效。 |
| **MQTT 保證送達（QoS 1）** | 每筆事件用 QoS 1 發送，伺服器沒收到就重發，封包不丟。 |
| **離線即時告警（LWT 遺言）** | 卡片斷線時伺服器立刻收到「離線」通知。哪台卡掉了，後台馬上看到。 |

### （五）全自動維運 — 不用人到現場

| 功能 | 說明 |
|------|------|
| **24 小時自動 OTA 遠端升級** | 每天上線自動檢查有沒有新韌體，有就自動下載更新。你不用派人帶筆電去現場刷機。 |
| **HTTPS 加密下載 + SHA256 驗證** | 韌體透過 HTTPS 下載，寫入後做完整 SHA256 校驗。被竄改的韌體刷不進去。 |
| **雙分區 A/B 備援切換** | 更新寫入備用分區，寫完才切換。更新失敗不會變磚，重啟就回到原版本。 |
| **防降級保護** | 不會被意外刷回舊版。 |
| **開機自動自檢** | 每次連上伺服器自動跑一輪硬體自檢（GPIO、計數器、記憶體、WiFi、MQTT）。問題在上線瞬間就被發現。 |
| **60 秒靜默心跳** | 60 秒沒操作就自動回報一次全通道狀態快照。有操作時自動重置計時器。既省流量，又不漏報。 |
| **機台活動偵測（120 秒）** | 機台開始活動時啟動 120 秒計時器，120 秒內無活動自動通報超時。哪台機半天沒動，系統直接告警。 |
| **LED 燈號狀態指示** | 燈號直接告訴你：WiFi 連線中 / MQTT 連線中 / 在線正常 / 升級中 / 系統錯誤 / 配網模式。水電工看燈號就知道狀態，不用開電腦。 |

### （六）一鍵批量部署 — 量大也不累

| 功能 | 說明 |
|------|------|
| **WiFi 感染式自動同步（專利級設計）** | 全場幾十台採集卡，只要第一台手動設定好 WiFi，這台就自動變成「母機」，對外廣播臨時熱點 15 分鐘。其他未設定 WiFi 的新設備開機後連線失敗 5 次，自動進入「子機」模式，搜尋到母機後自動取回 WiFi 帳密，連上主網路。一台配好，全場跟著連上，不需要一台一台手動設定。 |
| **手機直連配網** | 長按按鈕進入配網模式，手機連上採集卡熱點直接輸入 WiFi 密碼。不需要電腦、不需要拉線，手機設定 30 秒搞定。 |
| **USB 串口離線雙軌模式** | 採集卡的 Type-C 接上現場收銀電腦或 POS 系統。開分、洗分信號零延遲直送電腦，電腦回寫確認後卡片才定案。完全不需要網路，離線狀態下營收零丟失。 |
| **USB 純淨 JSON 輸出** | Type-C 只輸出業務資料，不混入系統除錯訊息。對接的 POS 系統不會被雜訊搞混。 |

## 三、雙核心硬隔離架構 — 為什麼別人的韌體會漏計？

本韌體最核心的技術門檻，是 **雙核心硬體級隔離設計**：

- **Core 1（採集核心）獨佔專屬**：只負責脈衝計數，不碰網路、不碰儲存、不碰任何會讓 CPU 停頓的作業。計數過程零中斷、零漏計。
- **Core 0（通訊核心）承載一切**：WiFi、MQTT 加密連線、OTA 下載、記憶體寫入，全部由另一顆核心處理。

一般廉價韌體把所有事情丟在同一顆 CPU 上跑，寫 Flash 時 CPU 停頓幾十毫秒，期間脈衝就漏計了。**漏一筆開分就是漏一筆錢**，日積月累帳目對不起來。

本韌體透過雙核心隔離，從硬體架構層面徹底消除這個問題。

| 功能 | 說明 |
|------|------|
| **32-bit → 64-bit 平滑遷移** | 舊版 32-bit 計數器的卡，更新韌體後自動讀取舊值並升級為 64-bit。舊卡的歷史里程不丟、不用歸零。 |
| **新舊通訊協定雙軌相容** | 同時支援新版 WAW-USS v1.0 通訊主題和舊版主題。舊伺服器不用改，新韌體直接相容。 |
