# WAW SignalHub - 後台 UI 規格（店主信號映射）

版本：v0.1.0 | 2026-08-31

---

## 總體規則

- 沿用 Owner 後台現有設計語言（Tailwind + Alpine.js）
- 大字清晰，高對比，緊湊排版
- 模組掛載在 Owner 後台 /signal-hub/ 路徑下
- 共 4 個頁面：設定檔列表、腳位映射編輯、統計規則、Webhook 設定

---

## 頁面 1：signal-hub/profiles（設定檔列表）

路由：GET /signal-hub/profiles
導覽位置：主選單「信號設定」下第一項

### 版面

頂部：
  [標題：信號設定檔]  [+ 新建設定檔] 按鈕（藍色）

篩選列：
  [搜尋名稱] [行業標籤下拉] [狀態：全部/啟用/模板]

表格欄位：
  設定檔名稱 | 行業標籤 | 綁定設備 | 腳位數 | 統計指標數 | 狀態 | 操作

操作欄：
  [編輯] [複製為模板] [查看統計] [刪除]

### 新建/編輯設定檔（Modal）

欄位：
  - 設定檔名稱（必填）
  - 行業標籤（自由輸入，有預設建議：遊樂場/餐飲/停車/自訂）
  - 說明（選填）
  - 綁定設備（搜尋下拉，可不綁定，作為模板）
  - 標記為模板（開關）

## 頁面 2：signal-hub/profiles/{id}/pins（腳位映射）

路由：GET /signal-hub/profiles/{id}/pins
從設定檔列表點「編輯」進入

### 版面

頂部麵包屑：信號設定 > 設定檔名稱 > 腳位映射

說明區（淺灰背景）：
  此設備共有 8 個腳位：UI1~UI4（輸入）、UO1~UO4（輸出）
  請定義每個腳位在您的機器上代表什麼含義。

腳位卡片列表（8張卡片，2欄Grid）：

每張卡片顯示：
  ┌─────────────────────────────────┐
  │ [UI1]  輸入腳位                  │
  │ 名稱：[____________] 必填        │
  │ 信號類型：[計數▼]               │
  │ 單位：[___] 倍率：[___]          │
  │ 統計分組：[________]            │
  │ 顯示顏色：[●] 顯示：[●開關]     │
  └─────────────────────────────────┘

信號類型選項（下拉）：
  計數器（脈衝累計）
  開關狀態（0/1）
  事件觸發（一次性）
  數值換算（帶比例）
  不使用（忽略）

底部：
  [儲存全部腳位設定] 按鈕
  [< 返回設定檔列表]

## 頁面 3：signal-hub/profiles/{id}/stats（統計規則）

路由：GET /signal-hub/profiles/{id}/stats

### 版面

說明：
  定義您想看到的統計指標。
  可以用腳位代號做數學計算，例如：UI1 - UI2 = 留存分數

現有統計規則表格：
  指標名稱 | 公式 | 單位 | 排序 | 狀態 | 操作

[+ 新增統計指標] 按鈕

新增統計指標（inline 展開表單）：
  - 指標鍵名（英文，程式用，例：net_credit）
  - 顯示名稱（中文，例：留存分數）
  - 計算公式（例：UI1 - UI2）
  - 單位（選填）
  - 公式說明（選填）

公式輔助提示：
  可用腳位：[UI1] [UI2] [UI3] [UI4]
  支援運算：+ - * / 以及括號
  範例：(UI1 - UI2) * 0.5

## 頁面 4：signal-hub/webhooks（Webhook 設定）

路由：GET /signal-hub/webhooks

### 版面

說明：
  設定當設備有信號時，自動推送到您的系統 URL。

Webhook 列表表格：
  目標 URL | 綁定設定檔 | 觸發腳位 | 失敗次數 | 最後成功 | 狀態 | 操作

[+ 新增 Webhook] 按鈕

新增 Webhook（Modal）：
  - 目標 URL（必填，https://...）
  - 簽名金鑰（選填，填入後會顯示 HMAC-SHA256 驗簽說明）
  - 綁定設定檔（選填，不選=全部設備）
  - 觸發腳位（多選 checkboxes：UI1 UI2 UI3 UI4 UO1 UO2 UO3 UO4，全選按鈕）
  - 觸發類型（多選：計數/開關/事件/數值）
  - 啟用（開關，預設開）

測試推送按鈕（建立後顯示）：
  [發送測試推送] → 顯示 HTTP 狀態碼和回應

## 共用元件

### 腳位選擇器元件（PinSelector）
用在 Webhook 的「觸發腳位」和統計規則的公式輔助

顯示方式：
  [UI1] [UI2] [UI3] [UI4] | [UO1] [UO2] [UO3] [UO4]
  點擊可選/取消選，選中的腳位背景變藍

### 公式建構器元件（FormulaBuilder）
用在統計規則頁面

顯示：
  文字輸入框（可直接輸入公式）
  下方顯示腳位快捷按鈕：點擊插入至游標位置
  即時預覽（用最近一筆信號計算結果）
