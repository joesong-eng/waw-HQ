# 📡 WAW SignalHub

> **定位**：WAW 信號接入標準子專案  
> **版本**：v0.1.0 (2026-08-31)  
> **狀態**：設計階段

---

## 🎯 這是什麼

SignalHub 是 WAW 平台對外開放的**信號接入層標準**。

核心思路：
- WAW 制定 ESP32 採集卡標準（硬體 + 韌體協議）
- 第三方按標準接入，自己定義信號含義
- WAW 後台提供統計、報表、管理工具
- 每台接入設備收授權費 ← 這是主要收入

---

## 🏛️ 四層架構

```
Layer 0  WAW 標準局        ← 你升級後的角色（賺授權費）
         ↓ 授權費
Layer 1  平台商            ← 目前你自己先做樣板
         ↓ 訂閱費
Layer 2  店主/機台主       ← 新增「店主層」，自定義信號映射
         ↓ 設備服務
Layer 3  玩家              ← 終端使用者
```

---

## 📦 信號映射概念

ESP32 採集卡有 4 個輸入腳位（UI1~UI4）和 4 個輸出腳位（UO1~UO4）。

店主自己在後台定義每個腳位的含義：

| 腳位 | 店主A（彈珠台）| 店主B（飲料機）| 店主C（停車場）|
|------|---------------|---------------|---------------|
| UI1  | 投幣計數      | 出貨感應      | 車輛進場      |
| UI2  | 洗分按鈕      | 補貨警示      | 車輛出場      |
| UI3  | 故障警報      | 溫度異常      | 滿場警示      |
| UI4  | 開分確認      |（未使用）     | 繳費完成      |
| UO1  | 開分繼電器    | 補貨指示燈    | 開閘桿        |

WAW 不需要知道「這是彈珠台」，WAW 只管信號進出和計數。
含義由店主在後台自定義。
