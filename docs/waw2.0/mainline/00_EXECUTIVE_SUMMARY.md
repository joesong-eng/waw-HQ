## 🎯 WAW 2.0 是什麼？

WAW 2.0 是 wawIoT 遊藝場管理系統的大規模重構計劃，目標是：

1. **修復五大跨模組 Bug**（前端 Token 污染、路由衝突、架構越權等）
2. **拆分 V9 單體系統**為 `waw-business`（人）和 `waw-iot`（物）
3. **實作軟性欠費機制**（欠費不停機，繼續服務但累計欠款）
