## 🎯 階段四核心目標

**服務拆分架構**：將 WAW 2.0 單體服務拆分為雙服務架構
- **waw-iot** (Port 8002): 物理採集、MQTT、硬體通訊、交易處理
- **waw-business** (Port 8001): 會員管理、營運後台、金流處理  
- **Nginx 反向代理**: 智能路由 `/api/iot/*` → 8002, 其他 → 8001
