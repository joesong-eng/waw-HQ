### 2. 讀取現有設定
頁面載入時呼叫 SignalHub API：
`GET /api/signal-profiles/{profile_id}/live-config`
填入當前值顯示。

### 3. 儲存設定
儲存按鈕呼叫 SignalHub API：
`PUT /api/signal-profiles/{profile_id}/live-config`
Body：`{ "live_pin": 4, "live_timeout_sec": 180 }`

SignalHub API 會自動發 MQTT 至採集卡，Owner 後台不直接發 MQTT。

### 4. profile_id 取得方式
設備（chip_id）對應的 active signal_profile id，透過 SignalHub API 查詢：
`GET /api/devices/{chip_id}/active-profile` （Sidney 應一併提供此 endpoint，如無則協調）
