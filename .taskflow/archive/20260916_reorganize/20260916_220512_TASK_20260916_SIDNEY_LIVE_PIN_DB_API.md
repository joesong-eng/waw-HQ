## 工作項目

### 1. DB Migration — signal_profiles 新增欄位
```php
$table->tinyInteger('live_pin')->nullable()->comment('0=停用,3=UI3,4=UI4');
$table->unsignedSmallInteger('live_timeout_sec')->default(120)->comment('30~600秒');
```
- 建立新 migration 檔案，不動現有欄位

### 2. API：讀取設定
**GET** `/api/signal-profiles/{id}/live-config`
- Auth：Bearer token（owner 範圍）
- Response：
```json
{
  "live_pin": 4,
  "live_timeout_sec": 180
}
```

### 3. API：更新設定 + 發 MQTT
**PUT** `/api/signal-profiles/{id}/live-config`
- Auth：Bearer token（owner 範圍）
- Body：`{ "live_pin": 4, "live_timeout_sec": 180 }`
- 校驗：live_pin ∈ {0,3,4}，live_timeout_sec ∈ [30,600]
- 存 DB → 發 MQTT `set_live_config` 至該 profile 綁定的 chip_id
- MQTT Payload 格式見 Coli 工單

### 4. SignalHub 管理 UI
`profiles/{id}/pins` 頁面新增：
- 「存活感測腳位」下拉：停用 / UI3 / UI4
- 「無活動逾時（秒）」數字輸入（30–600）
- 儲存按鈕 → 呼叫 PUT API

### 5. session_end 事件接收
現有 webhook/signal event 接收端新增 event type `session_end`：
- 記錄至 `signal_events`（event='session_end', reason 存入 meta 或獨立欄位）
- 不需要立即對 Sophie 推播（Phase 2 擴展）
