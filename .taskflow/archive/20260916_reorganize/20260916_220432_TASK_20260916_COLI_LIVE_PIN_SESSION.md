## 任務目標

實作 Live Pin + Session Timeout 偵測機制，使採集卡能偵測玩家離場（非洗分離場）。

---

## 工作項目

### 1. NVS 持久化
- 新增 NVS 鍵：`live_pin`（uint8, 預設 0=停用）、`live_t_sec`（uint16, 預設 120）
- 開機時讀取並套用至執行期變數

### 2. MQTT 指令：`set_live_config`
- Topic：`waw/v1/{site_id}/cmd/{chip_id}`（向下相容 `device/{chip_id}/cmd`）
- Payload：
```json
{
  "command": "set_live_config",
  "transaction_id": "txn_xxx",
  "params": {
    "live_pin": 4,
    "timeout_sec": 180
  }
}
```
- 參數校驗：live_pin ∈ {0,3,4}，timeout_sec ∈ [30,600]
- 校驗通過 → 寫 NVS → 更新記憶體 → 回覆標準 ACK（status: "success"）
- 免重啟即時生效

### 3. Session 狀態機
```
[IDLE]
  │ UI1 脈衝
  ▼
[SESSION_ACTIVE] ── 啟動計時器(live_timeout_sec)
  ├── Live Pin 脈衝 ──▶ 重置計時器
  ├── UI1 再投幣 ────▶ 重置計時器
  ├── UI2 觸發 ──────▶ session_end(reason: cash_out) → [IDLE]
  └── 計時器到0 ─────▶ session_end(reason: timeout)  → [IDLE]
```
- live_pin = 0 時，Session 狀態機停用（不影響現有 UI1/UI2 行為）

### 4. session_end 事件上報
MQTT + Serial 雙軌，符合 SIGNAL_WEBHOOK_AND_SERIAL_STANDARD_v2：
```json
{
  "chip_id": "df1e4c4b1105",
  "event": "session_end",
  "reason": "timeout",
  "last_played_duration_seconds": 245,
  "occurred_at": "2026-09-16T21:35:00+08:00"
}
```

### 5. PlatformIO 編譯驗證
- `pio run` 必須 0 error 通過
- 版本號升級
