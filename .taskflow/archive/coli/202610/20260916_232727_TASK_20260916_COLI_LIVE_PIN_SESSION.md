## 任務目標

實作 Live Pin + Session Timeout 離場偵測機制，使採集卡能精確判定玩家離場（支援洗分離場與逾時無動作離場）。

---

## 具體工作項目

### 1. NVS 持久化存取
- 命名空間：既有配置命名空間
- 新增 NVS 鍵值：
  - `live_pin` (uint8，預設值 0 表示停用，支援 0/3/4)
  - `live_t_sec` (uint16，預設 120 秒，範圍 30 ~ 600)
- 開機初始化時讀取並賦值至執行期全域變數

### 2. MQTT 指令支援：`set_live_config`
- Topic：`waw/v1/{site_id}/cmd/{chip_id}`（向下相容 `device/{chip_id}/cmd`）
- Payload 格式：
```json
{
  "command": "set_live_config",
  "transaction_id": "txn_20260916_001",
  "params": {
    "live_pin": 4,
    "timeout_sec": 180
  }
}
```
- 行為規範：
  1. 參數校驗：live_pin 必須為 0/3/4，timeout_sec 必須介於 30 ~ 600。
  2. 校驗失敗回覆標準錯誤 ACK；成功則寫入 NVS。
  3. 免重開機，即刻更新記憶體變數與計時器週期。
  4. 回覆標準成功 ACK（status: "success"）。

### 3. Session 狀態機實作
```
[IDLE / 閒置中]
      │ 偵測到 UI1 (開分/投幣) 脈衝
      ▼
[SESSION_ACTIVE / 遊戲中] ── 啟動倒數計時器 (週期 = live_timeout_sec)
      │
      ├── Live Pin (UI3或UI4) 脈衝 ──▶ 重置計時器 (重新倒數)
      ├── UI1 再投幣/開分 ───────────▶ 重置計時器 (重新倒數)
      ├── UI2 觸發 (洗分) ───────────▶ 立即結束 Session，發布 session_end(reason: cash_out) → 回到 [IDLE]
      └── 計時器歸零 (逾時無動作) ────▶ 逾時結束 Session，發布 session_end(reason: timeout)  → 回到 [IDLE]
```
- 注意：若 `live_pin == 0`，則維持舊有行為，不啟動此逾時狀態機。

### 4. session_end 事件雙軌上報
符合 `SIGNAL_WEBHOOK_AND_SERIAL_STANDARD_v2` 規範（MQTT + 串口雙發）：
```json
{
  "chip_id": "df1e4c4b1105",
  "event": "session_end",
  "reason": "timeout",
  "last_played_duration_seconds": 245,
  "occurred_at": "2026-09-16T21:35:00+08:00"
}
```
