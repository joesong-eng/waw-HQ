## 📋 任務內容

## 問題
welcome.blade 與 play.blade 引用 https://unpkg.com/vue@3/... CDN 載入 Vue。
CDN 模式存在：
- 資安風險（外部依賴）
- 效能不佳（無快取、無 bundling）
- 離線環境失效

## 執行項目
1. 評估現有 Vue 用法範圍（welcome、play、各 partial）
2. 選擇方案：
   方案 A：Laravel Mix/Vite 打包前端資源（推薦）
   方案 B：下載 Vue 至 public/vendor/vue/ 並用本地 path
3. 方案 A 優先：建立 vite.config.js，將 Vue 3 + 必要模組打包至 public/build/
4. 將所有 <script src="https://unpkg.com/vue@3/..."></script> 改為 <script src="{{ mix('js/app.js') }}"></script>
5. 確認 CSP header 設定（若有）允許 self
6. 視覺與功能驗證

## 驗收

2. DevTools Network 確認 Vue 從同源載入
3. Lighthouse Performance 分數不退步

5. 推送 origin/main
