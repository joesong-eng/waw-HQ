## 📋 任務內容

## 問題
目前 welcome.blade 與 play.blade 使用：
  import from 'https://unpkg.com/vue@3/...'
CDN 不穩定時前端白屏，且無法 tree-shake、無版本鎖定。

## 執行項目
1. 確認 Member 專案 vite.config.js / package.json 是否已有 Vue plugin
2. 若無，安裝 @vitejs/plugin-vue 並設定（但 pnpm install 只在遠端做，本地不跑）
3. 建立 resources/js/vue-entry.js 或直接在現有 app.js 引入 Vue 3
4. welcome.blade.php 與 play.blade.php 移除 CDN import，改用 @vite(['resources/js/app.js'])
5. 確保 Blade 元件的 <script type="module"> 內部邏輯可順利引用 Vue global
6. php -l 通過
7. Commit 訊息：feat(frontend): migrate Vue CDN to Vite bundling (P2-1)
8. 推送 origin/main
9. 遠端執行 npm run build（透過 waw_ops.sh 或 ssh）
10. 部署至 129.146.103.177（dev_tools/waw_ops.sh deploy mina）
11. 驗收：https://win.tg25.win 首頁、play 頁面正常渲染，Vue 響應式功能正常
12. 回報 Commit Hash 與驗收結果至 outbox
