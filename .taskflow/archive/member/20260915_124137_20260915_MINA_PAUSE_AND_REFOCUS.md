### 使用者真正的第一現場

**1.「我點進去，直接噴 500 錯誤畫面」**
未登入點進 Venue 頁面，原本可能只是一張草稿頁，現在直接跳 HTTP 500 Server Error（Header injection）。使用者心態：「這系統壞了」、「這是詐騙網站吧」。我們為了安全合規加了 auth:sanctum，結果連基礎 redirect 都沒測通就當作「完成」，把未授權的行為變成崩潰畫面。

**2.「我用手機玩機台，突然不能連線了」**
P0-5 把 SSL 改成 verify => true，但 VPS 根本沒有 CA bundle，導致 cURL error 60。Member 後端打不到 Infra API，查不到 active-status、做不了設備狀態同步。使用者心態：「我錢投進去了，機台沒反應！」「點數卡住了！」這叫做教科書級的「好心辦壞事」——在紙面上修了 P0 安全漏洞，在現實中直接把線上通訊幹斷。

**3.「按鈕有沒有變好按？遊戲有沒有變穩？」**
使用者不在乎 Vue 是 CDN 還是 Vite 打包。不在乎 2500 行 blade 有沒有拆。不在乎 .gitignore 有沒有忽略 __pycache__。但使用者在乎投幣後 5 秒內能不能開分、洗分會不會吞錢、網路斷線會不會被吃點數。
