## 第一階段：P0 緊急修復（4 項）

### UX-P0-1：LINE 回調後 URL 帶明文 Token
- 檔案：resources/views/welcome.blade.php
- 問題：OAuth 回調後 Sanctum Token 和會員資料直接寫在 URL Query String，瀏覽器歷史、Referer、Access Log 可見
- 修復：改用 LINE OAuth Code Exchange 模式，後端透過 Session 或 HttpOnly Cookie 傳遞 Token，不在 URL 暴露
- 注意：此項需後端配合，你在 P0 後端任務完成後再處理此項
- 預估：3-4 小時

### UX-P0-2：掃碼手動輸入框預填真實 chip_id
- 檔案：resources/views/welcome.blade.php
- 問題：const manualChipId = ref('sr9adyxpdyt1tuf7'); 預填了真實 chip_id，玩家直接點確認會綁定隨機機台
- 修復：預設值改為空字串 ref('')
- 預估：1 分鐘

### UX-P0-3：Kiosk 流程大量 Debug Toast 洩露給玩家
- 檔案：resources/views/welcome.blade.php
- 問題：玩家在 Kiosk 儲值流程中看到 session ID、kiosk ID、view 狀態的 debug 訊息
  - showToast('Ping heartbeat: SID=' + exchangeSessionId.value, 'info');
  - showToast('Flow: SID:... | CID:... | View:...', 'info');
  - showToast('token: ' + (token.value ? token.value.substring(0,10) : 'NULL'), 'info');
- 修復：移除所有 debug toast，或用 if (app()->environment('local')) 包裹
- 預估：15 分鐘

### UX-P0-4：Venue 頁面無任何認證保護
- 檔案：routes/web.php
- 問題：/subscriptions、/devices、/billing 無 auth middleware，任何人可看場館設備清單、帳單金額、繳費帳號
- 修復：加入 auth middleware
- 預估：10 分鐘

## 第二階段：P1 邏輯/體驗修復（9 項）

### UX-P1-1：開分無二次確認
- 檔案：resources/views/play.blade.php
- 問題：doCredit() 選好開分數量後直接扣代幣送出，無 confirm，涉及金錢操作可能誤觸
- 修復：加二次確認（滑動確認或點擊兩次），與洗分操作對齊
- 預估：20 分鐘

### UX-P1-2：洗分用瀏覽器原生 confirm() — 嚴重破壞 UI 一致性
- 檔案：resources/views/play.blade.php
- 問題：if (!confirm('確定要執行洗分嗎？...')) return; 賽博龐克風格突然彈白色系統對話框
- 修復：用自訂 Modal 替換，與服務協議彈窗風格一致
- 預估：30 分鐘

### UX-P1-3：洗分後無進度反饋
- 檔案：resources/views/play.blade.php
- 問題：API 回 queued 後只顯示 toast「洗分指令已送出」，玩家不知道要等多久、是否成功。WS 斷線則永遠等不到結果
- 修復：
  1. 洗分後顯示進度條或等待動畫
  2. 加超時處理：30 秒內無 WS 回推顯示「洗分超時，請聯繫服務台」
  3. 允許手動查詢洗分狀態
- 預估：1 小時

### UX-P1-4：超時踢人邏輯可能誤殺
- 問題：120 秒無 API 活動就自動結束 session，但玩家在機台上玩遊戲時 API 活動間隔可能超過 120 秒
- 修復：超時邏輯改為看機台端活動（MQTT heartbeat），不只看手機端 API 呼叫
- 注意：此項需與 Ina 確認 MQTT heartbeat topic 與欄位
- 預估：1 小時

### UX-P1-5：Kiosk 初始倒數 60 秒太短
- 檔案：resources/views/welcome.blade.php
- 問題：startExchangeCountdown(60) 玩家綁定後只有 60 秒投幣
- 修復：初始倒數改為 120 秒
- 預估：5 分鐘

### UX-P1-6：Escrow 確認倒數 15 秒太短
- 檔案：resources/views/welcome.blade.php
- 問題：escrowConfirmCountdown.value = 15; 玩家可能還沒理解就被自動處理
- 修復：改為 30 秒
- 預估：5 分鐘

### UX-P1-7：Exchange 視圖未監聽 KioskRejected 事件
- 檔案：resources/views/welcome.blade.php
- 問題：setupKioskEcho 沒有監聽 KioskRejected，玩家在儲值機頁面投幣被退時不會收到通知
- 修復：在 setupKioskEcho 中加入 KioskRejected 監聽
- 預估：15 分鐘

### UX-P1-8：登入成功後顯示 Debug Toast
- 檔案：resources/views/welcome.blade.php
- 問題：showToast('token: ' + (token.value ? token.value.substring(0,10) : 'NULL'), 'info'); 玩家登入後畫面頂部彈出 token debug 訊息
- 修復：移除此行
- 預估：1 分鐘

### UX-P1-9：Dev Phone 登入殘留在 JS 中
- 檔案：resources/views/welcome.blade.php
- 問題：loginPhone = ref('+886****2333') 和 doLogin() 仍在 JS 中被 return，production 環境 /api/dev/token 回 403 但 Console 可呼叫
- 修復：移除 dev login 相關代碼，或用環境判斷包裹
- 預估：10 分鐘
