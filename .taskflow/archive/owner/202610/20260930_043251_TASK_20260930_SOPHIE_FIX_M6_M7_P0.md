## 2. M7 SettlementPolicy approve 方法補齊

### 檔案位置
`PROJECT/Owner/app/Policies/SettlementPolicy.php`

### 缺失現況
`SettlementController::approve()` 呼叫 `$this->authorize('approve', $settlement);`
但 `SettlementPolicy` 類別中完全缺少 `approve()` 方法，導致 Laravel Gate 判定未定義而一律拒絕，返回 403。

### 需補齊方法
在 `SettlementPolicy.php` 內新增 `approve` 方法：
```php
    /**
     * 檢查用戶是否可以批准結算單（機台主操作）
     */
    public function approve(User $user, Settlement $settlement): bool
    {
        // 管理員可批准
        if ($user->role === 'admin') {
            return true;
        }

        // 機台主（設備主）在場地主確認後可批准
        if ($settlement->device_owner_id === $user->id && $settlement->status === 'confirmed_by_venue') {
            return true;
        }

        return false;
    }
```
*(請依現有 `SettlementController::approve()` 期待的狀態機定義，檢查確認前置狀態是否相容)*
