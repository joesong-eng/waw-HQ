## 一、任務起點：realtime 頁面數字不更新

用戶反映 `https://iot.tg25.win/realtime` 頁面數字不更新。

### 診斷過程
1. 前端 build 檢查：`wss://iot.tg25.win:443/app/iot-9-key` ✅ 正確
2. 直連 v9 Reverb 6009：WS handshake **101** ✅ 成功
3. 經 nginx `/app/`：WS handshake **500** ❌ 失敗
4. 取得 nginx 實際 include 的設定：`/www/wwwroot/iot.tg25.win/.nginx/nginx.conf`

### 根因
```
nginx location /app/ → proxy_pass http://127.0.0.1:6002   ← v8 的 Reverb
但 v9 的 Reverb 實際跑在                       6009
```
瀏覽器帶著 v9 的 key（`iot-9-key`）連到 **v8 的 Reverb**（key 不符）→ 握手失敗 → 收不到 `device.updated` 事件 → 數字不更新。

### 修復
- 本機 `.nginx/nginx.conf`：`/app/` 反代 6002 → **6009**
- 走 Git（commit `a38ec4a`）→ push → 遠端 pull → nginx reload
- 驗證：經 nginx WS handshake **101** ✅

### 端到端驗證（關鍵）
以 WS 客戶端訂閱 `realtime` channel，觸發廣播後**實際收到事件**：
```json
{"event":"device.updated","data":"{\"device_id\":\"df1e4c4b1102\",\"data\":{\"coin_in_count\":27289,\"status\":\"online\"...}}","channel":"realtime"}
```
✅ 整條鏈路（事件 → Reverb → nginx → 瀏覽器）已通。
